# تفعيل المزامنة والإشعارات (Firebase)

الكود جاهز، باقي بس تربطه بمشروع Firebase وتنشر جزئين: قواعد الحماية (Firestore rules)
و الدالة السحابية (Cloud Function) اللي ترسل الإشعارات.

## 1. ترقية المشروع لخطة Blaze
لازم عشان تشتغل الدوال السحابية (Cloud Functions):
- روح لـ [console.firebase.google.com](https://console.firebase.google.com) → مشروع masahatna
- ⚙️ **Project settings → Usage and billing → Modify plan → Blaze**
- تربط بطاقة، لكن فيه حد استخدام مجاني كبير شهرياً ولن يخصم منك شي إلا لو تجاوزته بكثير (تطبيق بين شخصين بعيد جداً عن هذا الحد).

## 2. تثبيت أدوات Firebase (مرة وحدة على جهازك)
```bash
npm install -g firebase-tools
firebase login
```

## 3. تثبيت الحزم الجديدة
داخل مجلد المشروع:
```bash
npm install
cd functions && npm install && cd ..
```

## 4. نشر قواعد الحماية والدالة السحابية
```bash
firebase deploy --only firestore:rules,functions
```
لو طلب منك تفعيل أي API إضافي (Cloud Build وغيره)، وافق — Firebase يفعّلها تلقائياً.

## 5. تشغيل الموقع
```bash
npm run dev
```
افتح الموقع من جوالين مختلفين (أو متصفحين). كل واحد يختار اسمه (Moe / Rio) من أعلى الصفحة،
ويروح لـ **الإعدادات → الإشعارات → تفعيل إشعارات هذا الجهاز** ويوافق على إذن الإشعارات.

بعدها أي إجراء (رسالة، تغيير مزاج، إضافة/إنجاز مهمة) يظهر فوراً عند الطرف الثاني، ويوصله
إشعار على جواله حتى لو الموقع مقفل عنده.

## ملاحظات مهمة
- **الأمان**: ما فيه تسجيل دخول بالتطبيق — أي شخص يعرف بيانات الإعداد (firebaseConfig) يقدر
  يوصل لنفس المستند. مقبول لتطبيق خاص بين شخصين، لكن لا تستخدم نفس الإعداد لشي أكثر حساسية.
- **النشر على الإنترنت**: للحين التطبيق يشتغل محلياً (`npm run dev`). عشان الطرفين يستخدمونه
  من أي مكان، تحتاج تنشره على استضافة زي Vercel أو Firebase Hosting.
- **iOS**: الإشعارات على آيفون تشتغل بس إذا الموقع مُضاف لشاشة الرئيسية كتطبيق (Add to Home
  Screen) وعلى iOS 16.4 فأعلى.
